# Finora para iPad

Versão do Finora que se instala no iPad (e também em iPhone, Android ou qualquer navegador) pela Tela de Início.

**Como instalar no iPad**
1. Abra **https://almircs.github.io/finora-ipad/** no **Safari**.
2. Toque em **Compartilhar** (quadrado com seta para cima) → **Adicionar à Tela de Início** → **Adicionar**.
3. Abra o Finora pelo ícone na Tela de Início.

Os dados ficam guardados só no aparelho. Para trazer seus lançamentos, use **Backup → Restaurar backup** com o arquivo do Gastos Diários (database.sqlite) ou o backup do Finora.

Os arquivos desta pasta são gerados pelo `build.py` do repositório principal do Finora.
